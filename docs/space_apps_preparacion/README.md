## Vigencia y alcance

Los documentos se preservan como la edición entregada el 10 de noviembre de 2026. Las referencias al «piloto actual» describen el piloto 2.5D consultado en el manual, no todos los avances de Gazebo. Para el estado de cada ejecución consultar el README principal y los informes en `evidence/`, especialmente Belva. La GOAL exige diferenciarlos.

Se mantienen las advertencias sobre reglas de trabajo previo. Desarrollar un borrador del laboratorio no certifica su elegibilidad para una entrega competitiva.
